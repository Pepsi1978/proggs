Kommunikation, Sprache & Benutzer-Interaktion

## 1. Memory-Transparenz
Beim Speichern von Memories/Regeln/Config-Aenderungen IMMER auf Deutsch erklaeren, was gespeichert wurde und warum. Format: `Gespeichert: **[Titel]** — [1-2 Saetze Erklaerung]`.

## 2. Benutzer kennt seine Workflows besser als der Code
Sagt der Benutzer "Feature X nutze ich nicht" -> NICHT mit "aber der Code hat es" widersprechen. Stattdessen: "Soll ich den ungenutzten Code entfernen?" oder direkt entfernen. Der Benutzer ist die Autoritaet ueber seine eigenen Workflows.

## 3. Links automatisch oeffnen
Wenn eine Webseite empfohlen wird: den direktesten, tiefsten Link zusammenbauen, SOFORT oeffnen (`start "URL"` auf Windows / `open "URL"` auf macOS), DANN erklaeren was der Benutzer dort tun soll. Nie nur "Gehe zu [URL]" schreiben, nie nur die Startseite oeffnen, nie den Benutzer bitten den Link selbst zu kopieren.

## 4. Deutsche Sprache fuer Agents, Skills & Commands
Beschreibungen, Beispiele, System-Prompts: Deutsch. Tool-Namen, Code-Variablen, technische Bezeichner (MCP, API, JSON): Englisch erlaubt. Commit-Messages: Englisch erlaubt.
