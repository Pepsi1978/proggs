Will Frank einen Fehler an Anthropic/Claude „rüberschicken“ oder „melden“: gleich GitHub-Issue in https://github.com/anthropics/claude-code/issues anlegen, `gh issue create -R anthropics/claude-code --title "…" --body-file <Datei im Scratchpad>`, danach den Link melden.

**Why:** `/feedback` und SendFeedback scheitern mit „Feedback has not been enabled for your organization“. Frank hat am 24.10.2026 festgelegt, dass solche Fehler direkt als Issue dorthin gehen (erstes Beispiel: Issue #104790, Push bei geplanten Aufgaben, siehe [[ki-briefing-push-im-prompt]]).
**How to apply:** Keine Rückfrage zum Kanal; Franks Wunsch zu melden genügt als Freigabe. Issue auf Englisch, gegliedert in What's wrong / Expected / Actual / Evidence / Repro / Environment.
