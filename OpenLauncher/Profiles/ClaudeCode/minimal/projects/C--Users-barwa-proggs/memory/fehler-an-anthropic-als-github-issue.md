Will Frank einen Fehler an Anthropic/Claude „rüberschicken“ oder „melden“, lege ich gleich ein GitHub-Issue in https://github.com/anthropics/claude-code/issues an: `gh issue create -R anthropics/claude-code --title "…" --body-file <Datei im Scratchpad>`. Danach den Link melden.

**Why:** `/feedback` und SendFeedback scheitern mit „Feedback has not been enabled for your organization“. Frank hat am 24.10.2026 festgelegt, dass solche Fehler direkt als Issue dorthin gehen (erstes Beispiel: Issue #104790, Push bei geplanten Aufgaben, siehe [[ki-briefing-push-im-prompt]]).
**How to apply:** Keine Rückfrage zum Kanal mehr, Franks Wunsch zu melden genügt als Freigabe. Issue auf Englisch, gegliedert in What's wrong / Expected / Actual / Evidence / Repro / Environment. Weil es öffentlich unter Pepsi1978 erscheint: keine Namen, keine Mail-Adressen, keine Zugangsdaten, keine Sitzungs- oder Aufgaben-IDs.
