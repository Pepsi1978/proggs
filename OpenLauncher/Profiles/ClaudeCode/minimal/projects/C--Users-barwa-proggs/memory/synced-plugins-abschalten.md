metadata:
  type: reference
---

Plugins unter `minimal/plugins/synced/` (Marktplatz knowledge-work-plugins) kommen vom claude.ai-Konto. Abschalten in den Settings: `"enabledPlugins": {"<name>@synced": false}` – Schlüssel so im claude.exe-Code, nicht `@knowledge-work-plugins`. 21.09.2026: 17 ungenutzte Plugins in allen sechs Profilen (Windows ClaudeCode + ClaudeCodeMac, je minimal/standard/strict) abgeschaltet. Solche Änderungen immer in allen Profilen. Aktiv bleiben pdf-viewer und productivity. Siehe [[aktiver-config-ordner-openlauncher-profil]].
