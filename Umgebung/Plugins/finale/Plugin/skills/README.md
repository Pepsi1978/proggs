# skills/

Dieser Ordner ist absichtlich leer im Bundle.

Beim Einspielen auf einem neuen System werden hier vier **Symlinks** auf die echten Skills
in `~/.claude/skills/` angelegt. Die Skills selbst liegen im Bundle separat unter
`../../Skills/` und müssen ZUERST nach `~/.claude/skills/` kopiert werden.

Anleitung siehe `../../INSTALL.md`.
