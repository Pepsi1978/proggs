# Third-Party Fonts

The app bundles the following font families from the official Google Fonts repository so
font selection works immediately and offline on every supported Android device:

- Playfair Display
- Source Sans 3
- Great Vibes
- Caveat
- Lora
- Sora
- Space Grotesk
- Nunito
- Manrope
- IBM Plex Sans
- Nunito Sans
- JetBrains Mono

Source: <https://github.com/google/fonts>

All listed font files are distributed under the SIL Open Font License 1.1. The applicable
license texts and family metadata are available in each family's directory in the source
repository.
