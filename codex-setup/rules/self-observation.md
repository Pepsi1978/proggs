# Self Observation for Codex Setup

Directive 2 for Codex environment work:

- observe during the work, do not interrupt the user mid-task with proposals
- collect observations in these categories:
  - Fehler
  - Umwege
  - Effizienz
  - Wissensluecken
  - Muster
  - Benutzer-Hinweise
- persist user hints immediately when they affect the environment or workflow
- treat repeated failures and repeated user corrections as class-level alarms
- report end-of-task intelligence proposals in plain German only after the status message
