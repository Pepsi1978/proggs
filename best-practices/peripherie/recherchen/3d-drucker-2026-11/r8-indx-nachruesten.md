## 2. Welche Modelle? Gen 1 braucht kein Gen-2-Upgrade
- Kits existieren getrennt für: CORE One/+ (Gen 1, d. h. originales CORE One bzw. CORE One+), CORE One+ (Gen 2), CORE One L/L+. Kits sind nicht untereinander tauschbar: "The CORE One+ version is not compatible with the L" / "Do not order that kit for the CORE One L+."
- Das Gen-1-Kit (EUR 50 teurer als Gen-2-Kit) enthält zusätzlich GT1.5-Riemen/Riemenscheiben und thermische Expansion Joints (beim Gen-2-Kit "not included - already present on the printer"). Das originale CORE One wird damit zu "CORE One+ mit INDX" (Prusa-FAQ: "Yes, you will end up with CORE One+ with INDX").
- Das Gen-2-Upgrade ist NICHT erforderlich: Handbuch "The Gen 2 upgrade is not required for the Prusa INDX upgrade"; das Gen-1-Kit enthält optional die Gen-2-Teile, es gibt eine Begleit-Anleitung zum gleichzeitigen Einbau.
- CORE One L (ohne Plus): Kit funktioniert, "not the optimal experience", GT1.5-Riemen werden stark empfohlen.
- MMU3 muss vorher entfernt werden (INDX ersetzt MMU3).
- INDX nicht kompatibel mit MK4S, MK3S+ usw.
Quellen: https://www.prusa3d.com/en/product/indx-4-tool-conversion-kit-for-core-one-gen2/ (FAQ + What's in the Box), https://www.prusa3d.com/en/product/indx-8-tool-conversion-kit-for-core-one-l/ (FAQ), Handbuch https://help.prusa3d.com/wp-content/uploads/generated/prusa-indx-conversion-kit-for-the-prusa-core-one_2432_guide_1096223_en_2026-10-26-172654.pdf (Steps 3, 11, 12), https://help.prusa3d.com/article/assemblling-the-prusa-indx-core-one-with-the-gen-2-upgrade_1147602

## 4. Advanced Filtration, Kamera, HT-Hotend
- HT-Hotend (400 °C): NICHT kompatibel mit INDX. Prusa-Blog: "Please note: the HT Hotend is not compatible with INDX." Produkt-FAQ: "No, this hotend is made for single-extruder versions of the CORE One family. It is compatible with the Nextruder and does not work with induction heating." INDX max. Düsentemperatur 300 °C, Düsen aus oberflächengehärtetem Stahl (nicht für Dauerbetrieb mit abrasiven Filamenten; Prusa nennt ca. 10 kg PETG-CF oder 5 kg PC-CF). Wer 400 °C braucht, kann nicht beides haben. Der HT-Hotend-Umbau (EUR 199) lohnt nur ohne INDX.
  Quellen: https://blog.prusa3d.com/ht-hotend-is-out-plus-we-offer-new-materials-and-hightemp-sheets-for-core-one-l_138625/ , https://www.prusa3d.com/en/product/ht-hotend-upgrade-for-core-one-and-core-one-l/ , Specs auf https://www.prusa3d.com/en/product/indx-8-tool-conversion-kit-for-core-one-gen2/
- Advanced Filtration (HEPA + Kohle): Auf den Prusa-INDX-Fertigdrucker-Seiten wird "Advanced Filtration for CORE One" als Zubehör geführt und es gibt Prusa-Bundles "INDX 8-Tool + Advanced Filtration" (EUR 2.289) -> mit INDX nutzbar. Für die L-Variante steht in den Maßen "Add extra 70 mm depth if you want to install the Advanced Filtration System". Eine explizite Aussage "Filtration nach Nachrüst-Kit weiter einsetzbar" fand ich auf den Kit-Seiten NICHT; da Kit = gleiche INDX-Hardware wie der Fertigdrucker, ist es sehr wahrscheinlich kompatibel (Schlussfolgerung, nicht belegt). Der Kit-Lieferumfang enthält eine neue Top Cover mit automatischer Belüftung ("Top cover with automatic ventilation"); Kit behält "smart ventilation system" der CORE One+. Quellen: https://www.prusa3d.com/en/product/prusa-core-one-gen-2-indx-8-tool-advanced-filtration-bundle/ , https://www.prusa3d.com/en/product/prusa-core-one-gen-2-indx-8-tool/
- Kamera: "Camera for CORE One" (Prusa) bzw. Buddy3D-Kamera werden zusammen mit INDX-Fertigdruckern angeboten (u. a. https://www.prusa3d.com/en/product/prusa-core-one-gen-2-indx-8-tool-buddy3d-camera-bundle/). CNC Kitchen merkt an: nach dem Druck parkt der Kopf im Sichtfeld der Kamera. Für Nachrüst-Kits keine ausdrückliche Prusa-Aussage; wahrscheinlich kompatibel (Schlussfolgerung).
- Weitere Änderungen: Bauraum sinkt von 250x220x270 auf 248x205x270 mm (CORE One+), L+: 298x275x330 mm. Kammer bis 55 °C (L: 60 °C) bleibt. Gerätebreite mit 8 Spulenhaltern 620 mm.

## 5. 4 vs. 8 Tools, Erweiterung 4 -> 8
- Gleiche Hardware (Smart Head, Docking-Hardware, Dock-Montageplatte); Unterschied nur Zahl der passiven Tools und Spulenhalter (4 oder 8). Prusa-Produkt-FAQ: "The four-tool machine already has empty dock positions on the mounting plate, so you can add four more nozzles later."
- Offizielle Aussage: "You can add individual passive tools later." (Kit-FAQ).
- ABER: ein kaufbares 4T-auf-8T-Upgrade/Einzel-Tool war am 19.11.2026 nicht auffindbar. Prusa-Mitarbeiter (Tommy_Prusa3D CM, 24.8.2026, Blog-Kommentar): "4 to 8 tool update will only be quite a bit later at the current timeline." Forum (29.9./1.10.2026): "There seem to be no official upgrade kits available"; "there's no guarantee Prusa will make an upgrade kit"; Community druckt Halter selbst, rechten Filamentsensor (Prusa-Shop) muss man nachbestellen. Düsen derzeit nur von Bondtech.
  Quellen: https://blog.prusa3d.com/prusa-core-one-gen-2-indx-shipping-has-started-complete-printers-open-for-orders_137623/ , https://forum.prusa3d.com/forum/prusa-core-one-hardware-firmware-and-software-help/upgrade-of-prusa-core-one-gen-2-indx-4-tool-to-8-tool/
- Praxis: 8T-Kit hat "best per-tool value" (Prusa). Wer sicher mehr als 4 Materialien will: gleich 8T kaufen (Aufpreis EUR 230).
