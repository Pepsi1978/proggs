# Codex-Startregeln für proggs

Lies die passende Regelquelle vor der ersten inhaltlichen Antwort und vor jeder
Projektarbeit vollständig. Diese Datei ist der versionierte Codex-Einstieg;
OpenLauncher überschreibt sie beim lokalen Start nicht.

- **Cloud-Sitzung** (Codex Cloud, ChatGPT mit verwalteter Cloud-Umgebung oder
  Claude Code Remote): Lies `OpenLauncher/Profiles/ClaudeCode/sources/cloud.md`
  relativ zu dieser Datei vollständig und befolge die dortigen Cloud-Regeln.
  Sie gelten auch für Codex. Lade hier keine lokalen OpenLauncher-PC-Profile.
- **Lokale Sitzung am PC/Mac**: Lies die `AGENTS.md` neben dieser Datei, falls
  vorhanden. Sie enthält das vom OpenLauncher gewählte Profil und den Arbeitsmodus.
  Die Cloud-Regeln gelten bei lokaler Arbeit nicht.

Codex lädt pro Verzeichnis `AGENTS.override.md` vor `AGENTS.md`. Deshalb muss die
jeweilige Regelquelle ausdrücklich gelesen werden. Behalte die Regeln in ihrer
Quelldatei; erstelle hier keine Kopie davon.
