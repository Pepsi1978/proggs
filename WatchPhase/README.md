# Watch Phase

Nachbau des Zifferblatts der Huawei Watch GT für die Watch 3. Fertige Datei: `dist/WatchPhase.hwt`.

## Auf die Uhr bringen

1. Gadgetbridge aus F-Droid aufs Handy installieren und die Watch 3 dort koppeln: https://gadgetbridge.org/basics/topics/huawei-honor/
2. `WatchPhase.hwt` im Dateimanager mit Gadgetbridge öffnen und die Installation bestätigen.
3. Auf der Uhr das Zifferblatt lange drücken und „Watch Phase“ auswählen.

Mit einer Huawei-Entwickler-ID geht es auch über Huawei Health. Die Installation auf einer echten Watch 3 ist noch nicht getestet.
