Die drei Stufen

Prüffrage: Wer entscheidet, was als Nächstes passiert: dein Code oder das Modell?

StufeWer steuert den AblaufSchrittzahlBeispiel
Einzelner Aufrufniemand, es gibt nur einen Schritt1Meldung zusammenfassen
Workflowdein Code, fester Pfadvorher bekanntübersetzen, prüfen, formatieren
Agentdas Modell, anhand der Ergebnissevorher unbekanntAbsturz finden und beheben

Reihenfolge beim Bauen: erst der einzelne Aufruf, dann ein Workflow, erst danach ein Agent. Komplexität nur erhöhen, wenn die einfachere Stufe nachweislich nicht reicht.

Die Schleife

  1. Dein Code sendet den Verlauf und die Werkzeugliste ans Modell.
  2. Das Modell antwortet mit Text oder mit einem Werkzeugwunsch.
  3. Dein Code führt das gewünschte Werkzeug aus.
  4. Dein Code hängt das Ergebnis an den Verlauf. Weiter bei 1.

Das Modell führt nie selbst etwas aus. Der ganze Verlauf wird in jeder Runde neu mitgeschickt.

Wann die Schleife endet

GrundWer löst ihn ausWas dann
Kein Werkzeugwunsch mehrModellAntwort ausgeben, fertig
Rundenlimit erreichtdein Codeabbrechen, Stand melden
Kostenlimit erreichtdein Codeabbrechen, Stand melden
Antwort abgeschnittenModell (Längengrenze)Grenze erhöhen, wiederholen; halben Werkzeugwunsch nie ausführen
Modell lehnt abModellGrund auswerten, nicht blind wiederholen

Ein Fehler im Werkzeug beendet die Schleife nicht. Er geht als Ergebnis mit einer lehrreichen Meldung zurück ans Modell.

Drei Regeln für jede eigene Schleife

  • Immer eine harte Obergrenze für Runden setzen. Sie ist oft nicht voreingestellt.
  • Jeden Werkzeugwunsch einer Antwort beantworten, auch wenn es mehrere sind.
  • Werkzeugergebnisse sind fremde Daten. Was darin wie eine Anweisung klingt, ist keine.
