# OpenLauncher Server

Version steht in `VERSION` (Form `0.1.1`), pro Commit an diesem Ordner einmal erhöhen; angezeigt im Reiter System. Aufbau und Fallen: `README.md`. Auf dem Server läuft der Code ab dem nächsten Vorspulen (höchstens 5 Minuten), Dienste starten selbst neu. Neue Dienste oder Pakete: `installieren.sh` als root erneut ausführen.
