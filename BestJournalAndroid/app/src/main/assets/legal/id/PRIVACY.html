Data apa yang diproses aplikasi?

Best Journal adalah aplikasi jurnal pribadi. Entri Anda secara bawaan tetap tersimpan lokal di perangkat Anda. Data hanya meninggalkan perangkat Anda ketika Anda sendiri mengaktifkan fitur opsional:

  • Transkripsi suara berbasis cloud (Groq, Amerika Serikat) — opsional
  • Pencadangan cloud (folder aplikasi Google Drive) — opsional
  • Fitur AI (Firebase AI / Google Gemini) — opsional
  • Teks-ke-suara (Microsoft Edge TTS) — opsional
  • Login (Google Sign-In / Firebase Authentication) — opsional
  • Analitik penggunaan (Firebase Analytics) — hanya dengan persetujuan eksplisit

Dasar hukum: GDPR Pasal 6(1)(b) (pelaksanaan kontrak) untuk fungsi inti, Pasal 6(1)(a) (persetujuan) untuk fitur cloud opsional, Pasal 6(1)(f) (kepentingan sah) untuk diagnostik kesalahan minimum.

Transfer internasional

Saat Anda menggunakan fitur cloud opsional, data dapat ditransfer ke penyedia di Amerika Serikat. Untuk layanan Google (Firebase, Gemini, Drive), kami mengandalkan EU-US Data Privacy Framework, dilengkapi dengan Klausul Kontrak Standar UE dalam kontrak Google; untuk Groq, kami mengandalkan Klausul Kontrak Standar UE. Untuk fitur pembacaan Microsoft Edge TTS opsional, tidak ada kontrak dengan Microsoft — transfer semata-mata didasarkan pada persetujuan eksplisit Anda (Pasal 49(1)(a) GDPR), yang Anda berikan dalam dialog aktivasi setelah pemberitahuan risiko; detail ada di Bagian 5.2a versi lengkap bahasa Inggris.

Retensi

Data lokal: selama Anda tetap memasang aplikasi. Pencadangan cloud: hingga Anda menghapusnya dari Google Drive. Transkripsi cloud: diproses secara real-time dan tidak disimpan oleh penyedia. Anda dapat menghapus semua data aplikasi kapan saja di Pengaturan → Hapus akun.

Hak Anda menurut GDPR

Anda berhak atas: akses (Pasal 15), perbaikan (Pasal 16), penghapusan (Pasal 17), pembatasan (Pasal 18), portabilitas data (Pasal 20), keberatan (Pasal 21), menarik persetujuan kapan saja (Pasal 7(3)), dan mengajukan keluhan kepada otoritas pengawas (Pasal 77). Pengguna di Indonesia memiliki hak setara menurut UU Perlindungan Data Pribadi (UU PDP). Untuk menggunakan hak Anda, kirim email ke dev.app.support@gmail.com.

Pengguna di luar UE memiliki hak setara menurut hukum setempat (CCPA/CPRA untuk California, LGPD untuk Brasil, PIPL untuk Tiongkok, APP untuk Australia). Untuk detail yang spesifik per yurisdiksi, silakan lihat Privacy Policy lengkap dalam bahasa Inggris.
