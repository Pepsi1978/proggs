# Kategorie: Android Compose

Alles rund um Jetpack-Compose-basierte Android-Entwicklung.

Hier landet alles was sich auf moderne Compose-UI, Kotlin-Android, Material
Design 3, AGSL Shader, Compose-spezifische Performance-Patterns und ähnliche
Themen bezieht.

## Cluster (Unterkategorien)

| Cluster | Anzahl Einträge | Worum es geht |
|---------|----------------|--------------|
| [energy-effects](energy-effects/INDEX.md) | 5 | Sichtbare Elektrizität, Stromfluss, Funken, Glühen, Energie-Animationen in Compose Canvas |

## Wann hier reinschreiben

- Recherchen zu Jetpack-Compose-spezifischen Techniken
- Performance-Patterns rund um LazyColumn, LazyGrid, Canvas, Animatable
- AGSL-Shader-Themen
- Material-3-spezifische Komponenten
- Compose-Multiplattform (wenn Android-fokussiert)

## Wann NICHT hier reinschreiben

- Reines Kotlin (gehört in `algorithmen-konzepte/` oder eigene Kotlin-Kategorie)
- Plattformübergreifende Themen die nicht auf Compose-Spezifika eingehen
- iOS/SwiftUI (gehört in `ios-swift/`)

## Wenn ein neuer Cluster gebraucht wird

Beispiele für mögliche zukünftige Cluster in dieser Kategorie:
- `lazy-list-tricks/` — Performance und UX rund um LazyColumn/LazyGrid
- `material3-design/` — Material You, Theming, dynamische Farben
- `compose-multiplatform/` — Cross-Platform-Themen
- `canvas-grafik/` — generelle Compose-Canvas-Techniken (nicht nur Energy)
- `navigation/` — Compose Navigation, Type-Safe Navigation
- `state-management/` — ViewModel, Hilt, StateFlow, Saver

Cluster werden organisch angelegt sobald der erste Eintrag entsteht.
